# UI Redesign System

## Editorial × Neo Brutalism × Memphis × Japanese Print

## Objective

Redesign the entire application.

Do NOT simply restyle existing components.

The goal is to create a memorable product that immediately stands apart from generic SaaS dashboards while remaining professional, trustworthy, and highly usable.

The final design should feel like:

- an editorial magazine
- a premium printed report
- a modern design magazine
- Japanese woodblock printing
- Memphis geometric graphics
- Bento layouts

The UI should never feel like Bootstrap, Tailwind UI, Material UI, or shadcn copied components.

It should feel custom-designed.

---

# Design Philosophy

Imagine the website was printed on high-quality textured paper instead of displayed on a monitor.

Everything should communicate:

• confidence
• clarity
• craftsmanship
• personality
• precision

The interface should feel tactile.

Every card should look like an object.

Every section should feel intentionally composed.

Every page should be visually interesting without becoming distracting.

---

Hard shadows

Bold buttons

Flat design

No glassmorphism

No soft gradients

Small playful accents

Dots

Lines

Circles

Geometric decorations

The color palette should feel inspired by Japanese prints.

Use colors similar to:

Deep Ink Black

Prussian Blue

Indigo

Vermilion

Ochre

Muted Green

Paper White

Warm Cream

Slate

Avoid:

Pure black backgrounds

Neon colors

Bright gradients

Purple-heavy palettes

Glass backgrounds

Excessive transparency

---

# Background

The page background should feel like paper.

Examples:

subtle grain

light texture

halftone dots

small Memphis decorations

light printed imperfections

The texture must remain subtle.

Users should notice it only after looking carefully.

---

# Borders

Borders are a primary design element.

Use:

2px

or

3px

dark ink borders.

Every important card should have a border.

Borders create hierarchy.

---

# Shadows

Use hard offset shadows.

No blur.

Example feeling:

printed paper stacked on another sheet.

Never use soft floating shadows.

---

# Cards

Every card should feel like a printed information panel.

Cards should:

have strong borders

hard shadows

large padding

interesting layouts

editorial spacing

avoid looking identical

Different cards may have different internal structures while remaining visually consistent.

---

# Bento Layout System

The entire website should use Bento layouts.

Avoid long boring vertical stacks.

Instead create compositions of:

large cards

small cards

featured panels

highlight blocks

statistics

quotes

reviews

graphs

illustrations

Forms should also participate in Bento layouts.

---

# Typography

Typography is the hero.

Use hierarchy aggressively.

Large headings.

Editorial spacing.

Readable paragraphs.

Use monospace only for:

metadata

labels

timestamps

badges

Never use monospace for body text.

---

# Buttons

Buttons should feel printed.

Large.

Confident.

Bordered.

Bold.

Minimal radius.

Hard shadow.

Strong hover movement.

Hover should feel physical.

---

# Icons

Outline icons.

Consistent weight.

Minimal.

Never use colorful icon packs.

Icons support content.

They never become decoration.

---

# Decorative Elements

Allowed:

Halftone dots

Diagonal stripes

Corner circles

Simple waves

Stamp graphics

Grid lines

Editorial dividers

Never use:

random blobs

3D illustrations

floating abstract shapes

heavy gradients

---

# Images

Images should feel editorial.

Use:

large crops

strong framing

interesting aspect ratios

black borders

caption text

Never use generic stock-photo layouts.

---

# Forms

Forms should look premium.

Inputs:

large

bordered

clear labels

visible focus

printed appearance

No rounded pills.

No floating labels.

---

# Tables

Tables should resemble newspaper layouts.

Strong row separators.

Bold headers.

Excellent spacing.

Readable numbers.

---

# Animations

Minimal.

Purposeful.

Fast.

Allowed:

shadow movement

slight translate

small rotations

fade

Never use:

large scaling

bounce

parallax

long animations

---

# Mobile

The design must remain editorial on mobile.

Do NOT collapse everything into one endless column.

Preserve Bento feeling.

Create intentional grouping.

---

# Implementation Strategy

Redesign the application page by page.

For every page:

1. Rebuild the layout using Bento composition.
2. Improve typography hierarchy.
3. Replace generic cards with editorial panels.
4. Apply consistent borders and shadows.
5. Introduce subtle Memphis accents.
6. Use Japanese print-inspired colors.
7. Ensure every section has a clear visual focal point.
8. Improve spacing before adding decoration.
9. Maintain accessibility and readability.
10. Prioritize clarity over visual complexity.

Never perform a simple color swap.

Treat this as a complete visual redesign while preserving the existing functionality.
